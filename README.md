## How to Download and Run the Project

1. Clone the repository:
   git clone https://github.com/ManMetGames/mgp-AnonymousBrownie

2. Right click MGP_2526.uproject, select Switch Unreal Engine Version, choose 5.6.1

3. Open the .uproject file and select Yes when prompted to rebuild

4. Press Play in the Unreal Editor

Required software:
- Unreal Engine 5.6.1 via Epic Games Launcher
- Visual Studio 2022 with Desktop development with C++ and Game development with Unreal Engine workloads installed
